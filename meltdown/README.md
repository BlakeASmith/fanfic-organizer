# Meltdown — The Colander Clash

A short comic-book deckbuilder starring **Colander Kid (The Wailing Wonder)**. This is a standalone extra, not part of the Calibre plugin.

```bash
python -m meltdown serve --port 8766
# http://127.0.0.1:8766/
python -m meltdown demo --seed 7 --encounter goon
pytest tests/test_meltdown_engine.py
```

Opening stance is the Plastic Strainer of Destiny: **Sieve** (exile the first Status/Curse drawn each turn) or **Dome** (keep Block; leftover Block Bonks the front villain). Tantrum fills when Kid takes a hit. At 5, **Meltdown** makes Outbursts free and double, then Drowsy.

Hero art on the title card is the supplied Golden-Age Colander Kid illustration. The real-life photo was not copied into the repo.
